# Pulse Desk — roadmap

## Phase 1 — Foundation

- [ ] Explain monorepo, Node.js, npm workspaces and Docker.
- [ ] Bootstrap the NestJS API and Next.js interface.
- [ ] Run PostgreSQL locally with Docker.
- [ ] Create the first migration and health endpoint.

## Phase 2 — Product core

- [ ] Model users, clients and tasks in PostgreSQL.
- [ ] Create authentication and authorization.
- [ ] Build REST endpoints with validation, tests and OpenAPI documentation.
- [ ] Build the dashboard and task workflow in Next.js.

## Phase 3 — Production thinking

- [ ] Add Redis cache and a background queue.
- [ ] Add structured logs, error tracking and metrics.
- [ ] Add CI with GitHub Actions.
- [ ] Deploy a preview environment and document architecture decisions.

## What each phase teaches

| Topic | Why it matters |
| --- | --- |
| TypeScript | Safer code and clearer contracts. |
| NestJS | Scalable backend organization. |
| PostgreSQL | Data modelling, queries, indexes and transactions. |
| Next.js | Modern frontend and server rendering. |
| Docker | Repeatable development environments. |
| Redis and queues | Asynchronous work and performance. |
| Tests and CI | Confidence when changing code. |
| English | README, pull requests and technical communication. |
